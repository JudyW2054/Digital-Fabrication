<div class="textcontainer"> <p class="margin"></p> <h3>Final Project: </h3> <h4></h4> <p class = "margin"></p> Initially I was hoping my final project would help me read while I eat by turning the pages when a sensor detects my hand's presence. I was also looking to make a product that could help those with mobility problems or limited mobility who might have trouble with reading. My initial idea for a book page turner would be one with two sensors that allowed me to turn both forwards and backwards. I also hoped it would be able to detect a constant presence in front of the sensor that would cause several pages to be turned. Time unfortunately did not allow me to incorporate all of these aspects, but I did end up with a simple version of it to build up upon in the future. <p class = "margin"></p> <p class = "margin"></p> <p class = "margin"></p> The bill of materials: Ultrasonic sensor, Wood (base), DC motor, 3D printed holders for sensor and servo, and a lot of wires. <p class = "margin"></p> <p class = "margin"></p> After completing an MVP of this project that incorporated an arduino motor and two servos that would allow me to turn the page and adjust how long the motor would be on according to my hand presence, I realized a couple things: working with one or more servos was tough because of the coding-- especially if I wanted them to complete functions together, having a DC motor continuously turn then flipping what comes up would result in inconsistent pages being turned, especially because some pages would stick together, having the time the motor turns depend on a human's hand motion was unreliable since you would have to guess how much time was needed to turn the amount of pages you wanted, the motor position would have to be able to move along the z-axis since after turning several pages, the height of the pages would be different, the servo that had to hold the pages down had to be longer in case pages didn't come all the way down, and the sensor needed to be placed in a position where it could not be triggered by other motions easily. <p class = "margin"></p> <p class = "margin"></p> For the integration iteration, I added in a stepper motor for more control for every page, and I added in an elevator component for the stepper motor so it could change based on the page height.
