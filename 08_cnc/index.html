<div class="textcontainer"> <p class="margin"> </p> <h3>Week 8: CNC Milling</h3> <h4>Assignment: Make Something With CNC</h4> <p class = "margin"></p> For this project, Emma, Stephen and I worked together to create a keychain charm with a simple cat outline. The stl is: <a download href='joined_cat.stl'>Cat File</a> <p class = "margin"></p> <p class = "margin"></p> <img src="10.png" width=auto height=400 alt="Fixed Size Image" alt="placeholder for you about me image"> <p class = "margin"></p> With Jess's help, we cut a positive from modeling wax using the SRM-20. We used a 1/8" square end mill for roughing and a 1/16" round end mill for finishing. We decided to use the "faster cutting time" rather than "better surface finish" which Emma and I disliked the result of because the finer details in the cat were not as well cut. After marking the origin on our material, used VPanel to set the origin for the machine, and started cutting. Once we had our positive, we mixed up some 1:1 silicone to make the mold. We left the mold to harden over night since hardening was said to take 3-5 hours. <p class = "margin"></p> <img src="wax.png" width=auto height=400 alt="Fixed Size Image" alt="placeholder for you about me image"> <img src="9.JPG" width=auto height=400 alt="Fixed Size Image" alt="placeholder for you about me image"> <p class = "margin"></p> For a charm we went with bismuth alloy because I thought a metal charm would be fun to try. The toaster oven took about 13 minutes at pizza temperature to fully melt the bismuth allow. For our first try, Emma poured in a little too much metal, so the cast outline was rounded on the back and has overflow around it. I helped for a second attempt, so we could act quicker because the metal set fairly quickly. So while she poured I would use a toothpick to push the metal into the narrower areas like paws ears and tails. The second cast still didn't come out perfectly due to some overfilling and the toothpicking roughing the back surface, but it was much better than the first attempt. We made a third attempt but scraped the back too much with the toothpick. We found through all three attempts that the metal didn't want to flow to the narrower parts of the mold. After Emma dropped attempt number 3, we found out just how brittle the bismuth alloy was. <p class = "margin"></p> <img src="yas.png" width=auto height=400 alt="Fixed Size Image" alt="placeholder for you about me image"> <p class = "margin"></p> We then put one of the metal casts in the smallest vacuum forming machine to make a mold to cast chocolate in. Emma brought it home, and the result is below. <p class = "margin"></p> <img src="chocolate.png" width=auto height=400 alt="Fixed Size Image" alt="placeholder for you about me image"> <p class = "margin"></p> We also tried out the Drystone plaster. We added 2g of water to 10g powder. The instructions told us to use 1,750 rpm motor to mix it, but we used a smaller amount so assumed vigorously mixing should be okay. The plaster picked up a lot of fine details much better than the other materials, including the tool path. The grey smudges are from metal that remained stuck to the silicone mold after casting. <p class = "margin"></p> <img src="3.jpg" width=auto height=400 alt="Fixed Size Image" alt="placeholder for you about me image"> <p class = "margin"></p> Emma and I agreed the bismuth alloy was most likely too brittle to be used for a keychain, so next time an epoxy resin might work better. <p class = "margin"></p> <img src="1.jpg" width=auto height=400 alt="Fixed Size Image" alt="placeholder for you about me image"> </div>
